# Watch-time rules (style-independent)

Applies to every script in `queue/`, whatever style is active. To be extended by the analysis of the narrator-style reference reels (see the list in the project memory / next session).

## Current rules (from our own reels and the first reference batch)
- **Hook in the first 0–2 s:** a surprising claim, a common mistake or a direct question to "vos", under 8 words, with a headline that appears by 0.4 s. Frame 0 is the thumbnail: it must already show the headline.
- **Open loop by second 5:** segment 2 promises something that comes later ("y casi todos rompen su regla sin saberlo").
- **Body:** one fact per sentence (6–12 words), a new picture every 1.5–3 s, headline on most segments (max 3 words).
- **Re-hook every 8–10 s:** short pattern break ("Pero esperá…", "Y ahora, lo más lindo…") with `impact: true`.
- **Payoff at 30–38 s:** deliver the promise, land on an emotion (compartir, compañía, orgullo), not on a dry fact.
- **Ending:** comment poll with 2–4 short options + "Seguinos para más"; the last line should lead back to the hook so the replay feels seamless.
- **Length:** 35–45 s. With the Charon voice: 12–14 segments (~100–110 words).
- **Emotion:** vary `emo`, never the same three times in a row; 2–3 sensory/human moments per reel; no invented facts, no health claims.
- **Language:** rioplatense, voseo; only Spanish on screen.
